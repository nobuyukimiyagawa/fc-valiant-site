# 選手写真の置き場

ここに `<data-photo>.webp` を置くと、MEMBER ページのステージにその選手が立ちます。
ファイルが無い選手は自動でエンブレムの仮表示になります。登録作業は不要で、
置くだけ・消すだけで切り替わります。

ファイル名は member.html の各カードの `data-photo` と同じです。

## 撮影と加工のお願い

- 全身、正面、立ち姿。足元まで入れる
- 全員そろえる: 同じ距離・同じカメラ高さ（胸のあたり）・同じレンズ
- 背景は白か単色。あとで切り抜くので、床と体の境目が分かるように
- 服装はチームの黒Tシャツ
- 縦位置、被写体の高さ 1200px 以上
- 元データは JPG/PNG で可。切り抜きと webp 化はこちらで行います

## 仕上がりの形式（こちらで作ります）

- 背景を透過した webp
- 画像の下端＝足の裏。左右は体の中央が画像の中央
- 高さ 1400px 前後

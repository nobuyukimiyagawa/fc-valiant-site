# FC VALIANT 公式サイト（改修版）

熊本県社会人サッカーチーム **FC VALIANT** のホームページ。
参考サイト（fukuoka-city24.com）のエディトリアル様式を、
FC VALIANT のブランドカラー（ネイビー × ゴールド）に落とし込んで制作。

## 配色ルール

**黒は使わない。暗部はすべて紺で作る。** グレーも無彩色を避け、青寄りに振ってある。
色を足すときは `assets/css/style.css` の `:root` にあるトークンから選ぶこと。

| トークン | 用途 |
|---|---|
| `--navy-deep` | 最暗部。マニフェスト／スケジュール／ビジョン／コンタクト等の背景 |
| `--navy` | 基調。実績バー／スポンサー／フッター／サブヒーロー等の背景 |
| `--navy-2` | 紺のグラデーション明部 |
| `--ink` | 紙面（`--paper`）上の本文色。純黒ではなく紺寄り |
| `--navy-deep-rgb` / `--navy-rgb` | 上記の RGB。半透明の `rgba()` 用。**必ず本体トークンと揃える** |
| `--gold` / `--gold-deep` | `#e6c15c` / `#caa544` **暗色部専用**のアクセント |
| `--gold-ink` | `#7a5f18` **紙面（`--paper`）の上に置く金。** `--gold` は紙面で 1.54、`--gold-deep` でも 2.09 しかない |
| `--paper` / `--paper-2` | `#f4f2ec` / `#ffffff` 明部の背景 |
| `--grey` / `--grey-ink` | `#9aa4b8` / `#5a6478` 補助文字（暗部用／紙面用）。どちらも青寄り |

### 紺の明るさ 5段階

紺の濃さは 0〜4 のレベルで管理する。**手で色を書き換えず、必ずスクリプトを使うこと**
（`rgba()` 用の RGB トークンも同時に更新する必要があるため）。

```bash
python3 tools/set-navy.py        # 一覧と現在のレベルを表示
python3 tools/set-navy.py 3      # レベル3を適用
```

| Lv | 印象 | `--navy-deep` | `--navy` |
|---|---|---|---|
| 0 | 最暗。黒に近い紺 | `#060f24` | `#0a162f` |
| 1 | やや明るい | `#0a1730` | `#0f2143` |
| 2 | 明るい | `#0d1c3a` | `#142a52` |
| 3 | さらに明るい（**現在**） | `#112445` | `#1a3563` |
| 4 | かなり明るい。ロイヤルブルー寄り | `#162c52` | `#204074` |

5段階すべて WCAG AA 以上（最小 5.32:1）を満たすので、どれを選んでも可読性の問題はない。

### 色決め用プレビュー

URL に `?navy=0`〜`?navy=4` を付けると、その場でレベルを差し替えて表示できる。
左下にレベル番号のバッジが出る。パラメータが無いときは何も起こらない。

```
https://nobuyukimiyagawa.github.io/fc-valiant-site/?navy=3
```

実装は `assets/js/main.js` の先頭 `navyPreview()`。
レベルが確定したら `tools/set-navy.py` で本適用し、この関数は削除してよい。

ヒーロー写真は元画像が灰色寄りのため、`.hero__media::after` で紺のカラーティント
（`mix-blend-mode:color` / `opacity:.45`）を重ねて紺に寄せている。
濃くするとエンブレムの金が死ぬので `.45` より上げないこと。

本文・補助文字はいずれも WCAG AA 以上（最小 5.32:1）を満たしている。

## 構成

トップを短く保ち、情報量の多いブロックは専用ページへ分離した**ハイブリッド構成**（トップ=感情で惹く／詳細=各ページで深掘り）。

```
fc-valiant-site/
├── index.html            # トップ（Hero / TEAM / ACTIVITY / 3ティザー / CONTACT）
├── schedule.html         # 年間試合スケジュール（全日程・成績）
├── recruit.html          # メンバー募集要項（VISION・募集要項・FAQ・代表）
├── sponsor.html          # スポンサープラン（4段階）
├── assets/
│   ├── css/style.css     # スタイル（全ページ共通）
│   ├── js/main.js        # JSアクション（全ページ共通）
│   └── img/              # 画像素材
│       ├── hero.webp / team-group.webp / logo.webp / logo.png / favicon-64.png
└── README.md
```

## ページ構成

## MEMBER ページ（2026-09-14 ポスター化）

「舞台に立たせる」3D風ステージをやめ、スポーツポスターの文法に変えた（Panini／クラブの選手ポスター参照）。
- **ポスター**（`.stage`）＝ 紙のざらつき（SVGノイズを overlay）＋ 斜めのハーフトーン帯 ＋ 傾けた金の板 ＋
  巨大なローマ字（1行目=姓を実線、2行目=名を輪郭で。左端揃え）＋ 切り抜き写真。板と文字はわざと傾け、端は切らせる
  （整えすぎると安っぽくなる）。写真が無い選手はエンブレムを薄く置き「PHOTO COMING SOON」の札
- **名鑑カード**（`.mcard`）＝ 3:4 の小さなポスター。下端に上辺を斜めに切った金の帯（太い名前）＋紺の細い帯（かな・BORN）。左上にポジション。写真の切り口は帯の裏に隠す（`bottom:7%`）
- **ローマ字は `data-photo`**（`iwamura-naoki` → IWAMURA ／ NAOKI）から JS が作る。HTML に足すものは無い
- カードの板・写真・巨大文字は `main.js` の `initMembers()` が組み立てる。HTML は名前・かな・生年月日のまま
- `member.html?p=<data-photo>` でその選手のポスターを最初に出せる（共有リンク用）
- 写真は `assets/img/member/<data-photo>.webp`。下端は切りっぱなし（フェードしない。2026-09-14 クライアント指示）
- 旧ステージ画像 `stage-back.webp` / `stage-front.webp` は未使用（削除済み）
- ⚠️ `.stage__plate` は `color:#fff` を明示すること。外すと body の紺を継承して名前が消える（実際に出した）

## ヒーロー

写真の中のエンブレムとヘッダーのロゴで足りており、三重になっていた。

## 数字の帯（STATS）

「2021 創設年」と「∞ 可能性」の2つだけ。**4列グリッドに2つ置くと右半分が空いて貧相になる。**
左端と右端に振り、間を1本の金の線でつないでいる（創設から、これから先へ）。
線は読み込み時に左から引かれる。**数字を増やして埋めない。**確定していない実績を足すと信頼が落ちる。

## 文章のトーン

**端正に、フランクに。** 暑苦しくもせず、砕けすぎもしない。ビジネス用語は使わない。
軸は2つ。**地域とのつながり**と、**メンバーのこれからの支え**。
タグライン=「まちと、仲間と。頼れるクラブであること。」

VISION の2見出しもタグラインと同じ「〜であること」で揃えてある
（「まちの一部であること」「仲間の支えであること」）。構文の反復が芯になっているので、
片方だけ書き換えないこと。

### 使わない言葉

| 種類 | 例 | 理由 |
|---|---|---|
| 行政・政策 | 地方創生 / 創生 / 復興の貢献 | サッカークラブの声にならない |
| 会社の資料 | キャリア形成サポート / 事業づくり / ソリューション / 推進 / 両輪 | 同上 |
| 熱すぎる | 本気 / 熱量 / 衝動 / 勇敢であれ / 信じて走ります | 読み手を鼓舞しにいかない |
| 軽すぎる | OK / 大歓迎 / うれしい / たのしい / もちろん / 手ぶら感覚 / 感嘆符 | 安っぽく見える |

### 書き方

- 全体は敬体（〜です・ます）。ヒーローの `Be VALIANT.` だけがブランドの署名。
- **英字のアイブロウ（小見出しの上に置く飾りの英語）を足さない。**
  ヒーローにあった `KUMAMOTO FOOTBALL CLUB / SINCE 2021` は
  「AIっぽい」として削除した（2026-09-05）。情報を足していない飾りは置かない。
- ヘッジを重ねない。「〜たらいいなと思っています」ではなく「〜になっていく」と言い切る。
- 「〜たり、〜たり」を並べない。体言止めと短い言い切りで運ぶ。
- ひらがなに開きすぎない（たのしい→楽しい、ばらばらです→さまざまです）。
- 感嘆符は使わない。

### 色を触ったときの決まり

**金は明暗で使い分ける。** 暗色部は `--gold` / `--gold-deep`、紙面は `--gold-ink`。
`.sec-head__no` や `.teaser__lead b` のように**明暗どちらの節にも出る要素**があるので、
片方だけ直すと逆側が壊れる。必ず両方を確認する。

**`button` 要素は色を継承しない。** UA が `buttontext`（黒）を当てるため、
`.btn--ghost` のように `currentColor` 頼りの指定だと紺の上で黒文字になる。
`button.btn{color:inherit}` で防いでいる。**新しく button を足すときは注意。**

検証は透過を合成したうえで行う。4ページ×2幅（1280/390）で全テキストを実測すること。

一度フランクに振りすぎて「安っぽい」と指摘を受けた（2026-09-04）。
フランク＝口語ではない。**崩すのは熱量であって、品ではない。**

代表の言葉（`recruit.html` の `.staff__quote`）もこのトーンで書いてある。
**ご本人の発言として掲載するので、内容の確認を取ること。**

> **要差し替え（プレースホルダー）**: 会費・練習日時・募集ポジション・FAQ回答（recruit.html）、
> 金額・返礼内容（sponsor.html）は仮データ。
> 試合日程は 2026-09-04 に実データへ差し替え済み（下記）。
> 各HTMLの `<!-- ▼ -->` コメント箇所を実情報に更新してください。
> トップの「NEXT MATCH」ティザーは自動同期ではないので schedule.html の直近試合に手動で合わせてください。

## お問い合わせ（Instagram DM）

問い合わせフォームは廃止し、**Instagram の DM に一本化**した（2026-09-04）。
CONTACT は「用件を選ぶ → 文面をコピー → DM を開く」の3ステップ。
DM は文面を事前に入れられないため、用件別のテンプレートをコピーして貼り付けてもらう方式にしている。

### Instagram アカウント

公式アカウントは **[@fcv.official](https://www.instagram.com/fcv.official/)**
（FC VALIANT 熊本県社会人サッカーチーム）。2026-09-04 に実ブラウザで実在と DM 到達を確認済み。

アカウント名は `assets/js/main.js` の 1 行で管理している。
変更が必要になったらここだけを書き換える。HTML 側は触らなくてよい。

```js
const IG_HANDLE = "fcv.official";
```

| 生成されるURL | 値 |
|---|---|
| プロフィール | `https://www.instagram.com/fcv.official/` |
| DM | `https://ig.me/m/fcv.official` |

HTML 側の目印は次の3つ。全4ページに入っている。

- `data-ig="profile"` … プロフィールへのリンク
- `data-ig="dm"` … DM を開くリンク
- `data-ig-handle` … ハンドル表示（`@fcv.official` が入る）

空文字にすると Instagram のトップに逃がすので、アカウントを作り直す際も壊れない。

> **確認時の注意**: `ig.me` は curl などプログラムからのアクセスを弾き、
> **実在するアカウントでも 400 のエラーページを返す**（`ig.me/m/instagram` でも同じ）。
> アカウント名の確認は必ず実ブラウザで開いて行うこと。

用件テンプレートの文面は `assets/js/main.js` の `contactDM()` 内 `TEMPLATES` にある。
用件を増やす場合は、`index.html` のチップと `TEMPLATES` の両方に同じ文字列で追加する。

`<a class="sponsor-link" target="_blank" rel="noopener">` で各社サイトへ。表示高 50px。

**流し方は CSS アニメーションではなく `scrollLeft` を進める方式**（2026-09-06 に変更）。
こうすると指・ホイール・ドラッグでの横スクロールがそのまま効く。

- `.hero__bar-ticker` に `overflow-x:auto`。スクロールバーは隠してある
- **`scroll-behavior:auto` を明示するのが必須。** `html` 側の
  `scroll-behavior:smooth` を継承すると、毎フレームの微小な移動が
  打ち消されて一切進まなくなる（実際にこれで止まった）
- 位置は JS 側で保持する。`scrollLeft` は丸められることがあるため
- 1組ぶん進んだら1組ぶん戻す。各組が同一なので継ぎ目は出ない
- ホバー・フォーカス中は停止。ホイール／指／ドラッグ操作後は 2.5 秒で再開
- ドラッグ中は `.is-dragging` が付き、リンクのクリックを無効化する
- タブが裏に回ると rAF が止まるので、復帰1フレーム目（間隔100ms超）は間引く

**追加・差し替えの手順**
1. 元画像を白背景のまま用意する
2. 内容の外接矩形で切り出し、320×120 のタイルに余白18pxで中央配置（下のコードと同条件）
3. `index.html` の `.sponsor-run` に `<img class="sponsor-logo">` を1つ足す

複製はしないこと。**1組だけ書き、画面幅を埋める複製は `main.js` の
`initSponsorMarquee()` が自動で行う。** 静的に2組並べる方式だと、
広い画面で1周が画面幅に届かず流れが途切れる（実際にその不具合を出した）。
同関数は「半周でコンテナ幅を超える」まで組を複製し、速度を 55px/秒 に固定する。
リサイズ時も組み直す。

ヒーロー左下のタグは `SINCE 2021` から `SPONSORS` に変更した。

読み上げ対応: ティッカー自体の `aria-hidden` は外した。
**先頭の1組だけが読み上げ・タブ移動の対象**で、`initSponsorMarquee()` が作る複製には
`aria-hidden="true"` と `tabindex="-1"` を付けて二重読み上げを防いでいる。

### デザインシステム：どこを崩し、どこを揃えるか

**一つの面につき、主役の仕掛けは一つ。** トップは署名の金の板、SCHEDULEは巨大な日付、
RECRUITは斜めに切り替わる写真の境界、SPONSORはプランの横帯、MEMBERは承認済みポスター。
同じヒーローを全ページへ複製しない。本文・日程・価格・操作ボタンは水平で読む。

- **帯**：暗部では `--gold` の板に `--navy-deep` の文字。紙面の金文字・細い罫線は `--gold-ink`。
  次戦は紺の一枚の帯、スポンサーの各プランは左に4pxの紺の縦線を持つ水平な比較欄。
  角丸の宣伝カードは増やさない。ボタンは最小48px高の角形、補助操作は44px以上。
- **傾き**：署名の背景だけ `rotate(-3deg)`。集合写真の裏の板は `rotate(2deg)`。
  RECRUITの写真境界はPCで上端8%・下端0%、スマホで上辺5%の斜めカット。
  実際の本文・名前・料金を回転させない。装飾のはみ出しは面の内側だけに収め、横スクロールを作らない。
- **グレイン**：`.poster-paper` で既存MEMBERと同種の220px SVGノイズを繰り返す。
  `mix-blend-mode:overlay`、要素の不透明度 `.12`、ノイズのアルファ上限 `.55`。
  擬似要素は `z-index:0`、内容は `z-index:1`。文字にはノイズを重ねない。
  MEMBERの既存ポスター内の `.26` / `.22` はそのまま。
- **文字**：ページの英字主見出しはAnton・400。PCでおおむね64〜160px、スマホで54〜96px。
  日本語本文はNoto Sans JP、原則13〜16px・行高1.8〜1.95、補助情報は11〜13px。
  日付・価格・成績は `font-variant-numeric:tabular-nums`。データに十分な幅を先に割く。
  長文を狭い英字フォントへ置き換えない。巨大文字にするのは見出しまたは日付だけ。
- **情報の密度**：TEAMの成績・概要、FAQ、スポンサーの掲載位置はネイティブ `details`。
  トップは通常状態で4ブロック。詳細を開いて長くなることは許容し、内容を削って帳尻を合わせない。
  同寸の箱を使うのは試合結果・数値比較のような一覧だけ。
- **余白と幅**：紙面は最大1280〜1440px。左右余白はスマホ24px、PCは5〜6vw。
  節間はPCで42〜64px、スマホで28〜40px。各節の先頭に100px以上の空白を積まない。
- **重なりの階層**：背景0、本文・写真1、局所の見出し2、ページトップボタン150、
  共通ヘッダー200、開閉ボタン210、スキップリンク400。新しい全画面オーバーレイは追加しない。
- **ヘッダー**：常に不透明な紺。SCHEDULE → MEMBER → RECRUIT → SPONSOR → CONTACT。
  各リンクには既存の日本語の意味も添える。1100px以下はメニューへ。
  開いた間は本文・フッターを `inert` にし、Tabを循環、Escで閉じて開閉ボタンへ戻す。
- **動き**：新しい常時アニメーションは追加しない。既存ティッカーは55px/秒の `scrollLeft` 方式。
  見えない間・ホバー中・フォーカス中は進めない。手動操作後は2.5秒待つ。
  CTAの反応は180ms。`prefers-reduced-motion` ではスクロール・数値カウントを即時化する。
- **JS無し**：本文を隠すCSSは `.js` がある時だけ適用。メニューは折り返したリンクとして表示する。
  DMの初期文面・手動コピー用テキスト・Instagramリンク・FAQ・募集内容は読める。
  次戦自動判定・成績集計・用件切り替え・MEMBERポスターは従来どおりJSが必要。
